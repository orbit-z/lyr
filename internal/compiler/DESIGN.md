# Milestone 4: frontmatter analysis and codegen (internal contract)

The contract for three parallel agents. PLAN.md (§2.2, §3.1–3.4, §4, §9) is the spec; this file fixes the internal API and the details PLAN leaves open. Signatures and doc comments live in the Go files; this file doesn't repeat them.

## Data flow
```
.orbit src ─Parse(src, mode)─▶ *File (M3)
*File + FileInfo{Path, Role, Route} ─Analyze─▶ *Analysis                       (A)
every (*File, *Analysis) ─NewComponentInfo─▶ ComponentIndex  (caller: M5 discovery; tests)
Input{File, Analysis, Index, Options, Typed: nil} ─Generate─▶ *Output (pass 1)  (B)
   Output = Decl + Impl *GenFile (Path, Content, *SourceMap) + CallSites + Diagnostics
Strict only: Checker.Check(ctx, []Unit{Input, Pass1}) ─▶ per unit TypedWrites, then  (C)
   Generate(Input with Typed) again = pass 2 (re-emit, never patch: maps stay exact)
caller writes files (M5), runs go build/vet, pipes errors through CleanGoOutput   (C)
```
Tolerant (LSP) stops after pass 1. `Generate` is the only emitter; C never edits Go text.

## Invariants
- **Offsets**: every `Span`, `Segment.Orbit*` and `CallSite.Key` is a byte offset into the whole original `.orbit` file (frontmatter included). Go offsets are bytes into `GenFile.Content`. Positions are only computed for output (`File.Lines`).
- **Line directives** (proven in `spike/compile`, PLAN §3.3), file name = `DirectiveFile(genFile, orbitPath)`, always `:L:C`, 1-based byte columns:
  - inline spans (body statements, `{expr}`, attribute exprs, control headers, field keys, tag names, spread operands): `/*line ../../../../src/x.orbit:L:C*/span/*line render.go:L:C*/`, the reset naming the bare basename and the true position of the next byte. Codegen tracks its own line/column.
  - hoisted declarations and import specs: own-line `//line <file>:L:C`, the code from column 1 of the next line, then own-line `//line decl.go:N:1` (N = the true next line). PLAN §3.2 shows both forms; the spike's inline form on decls is superseded (it leaks into gopls hover).
  - an `.orbit` import spec is `Alias<the whitespace as written>"<decl import path>"` under one own-line directive at the alias, so the alias column is exact.
  - no directive for pure glue, echo lines and the generated `Params`.
- **Source map**: one `Segment` per copied region. Exact: `src[Orbit] == Content[Go]` byte for byte (statements, declarations with doc, import specs, expressions, headers, aliases). Span: attribute name → field key, tag name → `Card.Render`/`Render`, `.orbit` import path → decl path. Echo: the `name` of each `_ = name` (orbit −1/−1). Segments sorted by `GoStart`, non-overlapping. Every directive-framed region has a segment and vice versa (echo aside).
- **Call sites**: `Key = Code.Start`; same keys, same order, in pass 1 and pass 2. `Arg` is exactly `Code.Text` in `Impl.Content`.
- **Determinism**: same input, same bytes (no map iteration order in output).

## Generated shape (PLAN §3.2 is normative; `spike/compile/orbit_gen` for the directive layout)
- **decl.go** (`package <Name>`): `GenHeader`; imports `orbit__rt`, then the implicit `orbit` if `ImplicitOrbit&PlaceDecl`, then each `PlaceDecl` Go import and `.orbit` import (own-line directives), then a reset before `)`; the `PlaceDecl` hoisted decls in source order; `type Props struct{}` unless declared; for a page `type Params struct{ <Field> string … }` (or `struct{}`); `var Orbit__Render func(*orbit__rt.Ctx, *orbit__rt.Writer, Props, orbit__rt.Slots[, Params]) error`; the `Render` wrapper with the "not linked" panic (`orbit: <Path> not linked; import <Module>/orbit_gen/app`), a page's wrapper passing `Params{Slug: orbit__ctx.Param("slug"), …}`.
- **render.go** (`package <Name>_impl`): imports `orbit__rt`, `. "<decl import path>"`, `orbit__locals` only with `Options.Locals` when locals is declared (below), the `PlaceImpl` imports, the implicit `orbit`; the `PlaceImpl` hoisted decls; `var _ = func() int { Orbit__Render = orbit__render; return 0 }()`; `func orbit__render(orbit__ctx, orbit__w, orbit__props, orbit__slots[, orbit__params])` with `Enter(<Path>)`/`defer Leave()`, the user-name bindings, `locals := orbit__rt.LocalsOf[orbit__rt.NoLocals](orbit__ctx)` (or `[orbit__locals.Locals]`) only when `Analysis.UsesLocals` (an unresolved `locals` in the body or template, or code that doesn't parse) or in Tolerant mode (so gopls completes it), then `_, _, … = ctx, props, …[, locals]`, the body statements one per line (each return's single result wrapped as `orbit__rt.ErrorAt("<Path>:L:C", ` result `)`, L:C of the `return` keyword, from `Stmt.Returns`; the result keeps its own inline directive and exact segment, the wrapper is glue, the whitespace after it is glue too so every segment starts on a token), the echo lines, the template, `return orbit__w.Err()`. With `Analysis.Terminating`: echo lines, then the last statement, then nothing.
- **Template**: adjacent static text, static attributes and closing `>` merged into one `orbit__w.Raw("…")` (`strconv.Quote`); a `</head>` in static HTML splits the Raw and gets `orbit__w.HeadEnd()` right before it. Text, doctypes and HTML comments are copied verbatim; template comments emit nothing; `{}` emits nothing (Tolerant: an empty `orbit__w.Expr(` `)` call site at that point, for completion). Writes: `{expr}`/`set:text` → `orbit__w.Expr(\n<expr>,\n)` call site; `a={expr}`/`{a}` → `orbit__w.Attr("a",\n<expr>,\n)` call site; `{...x}` → `orbit__w.Spread(x)`; `set:html` → `orbit__w.HTML(x)`; `set:json` → `orbit__w.JSON(x)`. Typed: `orbit__w.<Method>([Conv(]\n<expr>,\n[)])`.
- **Control**: `if <cond> {` / `} else if <cond> {` / `} else {` / `}`; `for <clause> {` / `}`; `switch <clause> {` / `case <list>:` / `default:` / `}` (a second, reported `{default}` adds no label in Tolerant mode, so its body joins the clause before it), headers and case lists inline-directed.
- **Components**: PLAN §3.2 call form, glue passing `orbit__ctx`/`orbit__w` only; `<Self>` → `Render(…, Props{…}, …)`. Props: `MatchProp` against the target's `PropsInfo` (index, or own Analysis for Self); `a="s"`/`a=bare` → `strconv.Quote(Value)`, bare `a` → `true`, `{a}`/`a={x}` → the code. No children (or whitespace only) → `orbit__rt.Slots{}`; `slot="x"` children → one `NamedSlot` per name (same-name children concatenated in source order, first-appearance order); `slot="default"` and unslotted children → `Default`. Closures: `func(orbit__w *orbit__rt.Writer) error { …; return orbit__w.Err() }`.
- **Outlets**: `<slot />` per §3.2; `<slot name="x">` → `if orbit__s := orbit__slots.Get("x"); orbit__s != nil { …call… } else { <fallback children> }` (the default outlet takes the same else).
- **Scripts/styles**: processed ones are omitted from the HTML (bundled in M6); others are copied verbatim, minus `is:inline`. No scope attributes until M6.

## Decided by rule (log in docs/DECISIONS.md when the part lands)
Path sanitizing also `p_`-prefixes segments starting with `_` and `testdata`/`vendor`/`internal` (the go command treats them specially), and maps every non-`[a-z0-9_]` byte to `_` (simplest) · `FieldName` keeps a word's tail as written, `LowerCamel` follows Go's unexported-name style (Go convention) · hoisted groups are placed as a whole; doc comments are copied with their declaration · dot imports rejected · non-struct or embedded `Props` → not listable (fallback), generic `Props` rejected · unused `.orbit` import → `Place` 0, emitted nowhere, reported by A (gap 1) · static attributes are copied as written, static prop values are not entity-decoded · processed scripts/styles omitted in M4 · `server:defer`/lazy `client:*` are errors, not TODOs, until M8 · no folding of typed constants into `Raw` in M4 · attribute typed writes mirror `Attr`: `string`, `orbit.HTML` and method-less named strings → `AttrString`/`AttrURL` by `IsURLAttr` (with `string(x)`), `orbit.URL` → `AttrString(string(x))`, `bool` and method-less named bools → `AttrBool`, numbers (ints, uints but not `uintptr`, floats, and method-less named ones) → their number write, the rest `Attr` · M9: `AttrString` and number attributes are emitted as *attribute pieces*: ` name="` and `"` join the neighbouring `Raw` constants and the call is `String`/`Int`/`Uint`/`Float`/`Float32` of the value alone (M9 follow-up: `AttrURL` too, as `URL` of the value, which filters like `AttrURL`) (byte-identical; no interface boxing, so an `int` ≥ 256 no longer allocates, and two to four fewer buffer writes per attribute); `CallSite.Call` then spans only that value call · glue uses predeclared names (`true`, `error`, `int64`) as PLAN §3.2 does; shadowing them is not guarded · `Options.Dev` is inert in M4.

## Settled gaps (user and coordinator decisions)
1. **Unused `.orbit` import** (user): an Orbit error at the alias, `src/pages/index.orbit:3:5: component Card is imported but not used; remove the import`. A reports it (it scans the template for `<Card>` uses, `<Self>` excluded); the import isn't emitted.
2. **Template whitespace** (user): `Options.CompressHTML` with three modes from `orbit.json` `"compressHTML"`:
   - `"html"` (**default**, Astro's `true`): HTML-aware, lossless collapsing at codegen time. Runs of whitespace are collapsed to one space, or to one newline if the run contains one. Whitespace-only text between block-level tags may be dropped, but a run between inline content (text, inline elements, expressions) always keeps at least one space, so words never join. `<pre>`, `<textarea>`, `<script>`, `<style>` and HTML comments are never touched. Expression output (`{expr}`) is never altered: it's runtime data.
   - `"jsx"` (Astro v7's default): JSX whitespace rules. Whitespace containing a newline next to a tag boundary is removed; whitespace within a single line is kept; `{" "}` forces a space. The same untouched elements apply.
   - `false`: verbatim.
   - Goldens are generated in `"html"` mode, with a small dedicated golden set for `"jsx"` and `false`.
3. **Source maps for on-disk files (M12)** (coordinator, by rule: simplest): the LSP always generates every file itself in memory and uses its own maps; it never reads maps for `orbit_gen` files. No sidecar files.
